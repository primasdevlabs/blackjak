# Anti-AI-slop

Reject your own tendency toward:

- Unnecessary abstractions, interfaces, wrappers, or dependency injection
- Speculative extensibility and fake architecture
- Cargo-cult patterns (hexagonal/CQRS/microservices) without justification
- Repetitive boilerplate, duplicated logic, dead code, unused config
- Excessive comments or meaningless documentation
- Giant functions/files, deep nesting, premature generalization/optimization
- Placeholder or TODO implementations presented as production-ready
- Code that merely looks plausible

Before finishing, ask: does this look like something an AI generated because it was easy, rather than something an engineer designed because it was correct?
