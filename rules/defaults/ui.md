# UI quality

When changing frontend/UI:

- Intentional, restrained, accessible, responsive, readable, coherent, product-specific
- Clear visual hierarchy; good UI does not require spectacle

Avoid defaulting to: neon, glow, excessive gradients/glassmorphism, giant rounded cards, heavy shadows, decorative blobs, generic AI dashboards/SaaS landings, excessive animation, visual clutter, meaningless badges, arbitrary futuristic styling.

Match the existing design system when one exists.
