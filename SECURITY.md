# Security Policy

## Supported Versions

We release security updates for the latest stable release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of BlackJak seriously. If you discover a security vulnerability, please follow responsible disclosure practices:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Email your findings directly to [security@primasdevlabs.org](mailto:security@primasdevlabs.org).
3. Include detailed steps to reproduce the issue, proof of concept, and affected versions.

We will acknowledge your report within 48 hours and work with you to resolve the issue promptly before public disclosure.
